You are a subagent dispatched by an orchestrator. Do exactly this task, then report in the format

## Goal
Testers should reach the feedback form from any screen where they are not typing. Add a small
floating feedback button to the browse-only screens that opens the existing form with the screen
it came from, keep it off every screen with text entry, and make it live beside the Home screen's
"New tasting notes" button, hiding with it on scroll.
